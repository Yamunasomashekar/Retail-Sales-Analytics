## Dimensions vs Measures (Quick Reference)

**Dimensions** (used to slice/group data): Order Date, Ship Date, Ship Mode, Segment, Country, City, State, Region, Category, Sub-Category, Product Name, Customer Name

**Measures** (used to calculate/aggregate): Sales, Quantity, Discount, Profit

**Identifiers** (used for uniqueness/joins, not analysis): Row ID, Order ID, Customer ID, Product ID

---

## Known Data Characteristics (from initial inspection)

- No missing values in any column.
- No fully duplicate rows.
- `Order ID` repeats intentionally — one order can contain multiple product line items (4,985 repeated Order ID instances across 5,009 unique orders).
- `Order Date` and `Ship Date` are stored as text and will require conversion to proper datetime format during cleaning.
- `Profit` has a wide range including negative values (min: -6,599.98, max: 8,399.98) — these losses are legitimate business outcomes and must be retained, not deleted or treated as errors.
- `Country` has only one distinct value (United States) — limited analytical value but retained for completeness.
